## What we learned (15–16 Oct)

1. Aimed fights, with every mismatch shrunk and traced, give the most fix-ready information per CPU minute.
2. A cheap Sonnet fixer plus an Opus reviewer works. The mirror fix:
   - first round about 20 minutes; Opus rejected it for a real flaw (removal screens list curses first);
   - the amend was accepted.
3. The "1,260 different card upgraded" Codex stops are **not** a list-order bug. They are a Walker measurement gap: the game draws Rng.Niche for every creature that joins a fight, and the history does not record how many. A probe that treats this count as a hidden fact lets about 781 more runs complete; 1 run gets worse.
4. The order audit (`audit-order.md`) found ordering mostly right: about 257 sites, 4 small mismatches.
5. Enchant eligibility: 25 Codex runs stop because a card the player enchanted is "not selectable" in the emulator. This is a real engine bug.
6. RunEngine.Reset leaks state between runs on one handle. It affects the Python env only, not our fidelity tools.

Each of these has a line in `ledger.md`.
